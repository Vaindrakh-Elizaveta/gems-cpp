# GEMS C++

Учебный проект на C++: реализация игры в жанре match-3 с игровым полем, обработкой ходов, поиском совпадений и системой бонусов.

## Возможности

- игровое поле из цветных клеток;
- выбор двух соседних клеток и обмен их местами;
- поиск групп из трёх и более одинаковых клеток;
- удаление найденных групп;
- обновление игрового поля после удаления клеток;
- реализация бонусов:
  - перекрашивание клеток в окрестности;
  - бонус “бомба”, уничтожающий несколько клеток на поле.

## Технологии

- C++
- ООП
- Visual Studio
- Windows desktop application

## Структура проекта

- `main.cpp` — точка входа в приложение;
- `Game.*` — основная игровая логика;
- `Board.*` — работа с игровым полем;
- `Cell.h` — описание клетки игрового поля;
- `Bonus.h` — логика бонусов;
- `GEMS.vcxproj` — проект Visual Studio.

## Как запустить

1. Открыть проект в Visual Studio.
2. Собрать решение.
3. Запустить приложение.

## О проекте

Проект выполнен в рамках учебного курса по C++.
Основной акцент сделан на объектно-ориентированное проектирование, реализацию игровой логики, работу с состоянием игрового поля и алгоритмы поиска совпадений.
